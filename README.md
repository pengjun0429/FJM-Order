## 🚀 PR 概述
此 Pull Request 主要進行了前端程式碼的完整性修復與優化，解決了之前程式碼結構不完整（被截斷）的問題。在未刪除任何既有功能的前提下，補齊了所有遺失的 HTML 標籤、CSS 動態樣式、彈窗互動，以及核心的 JavaScript 邏輯。

## 🛠️ 修改內容
1. **結構與樣式修復**：補齊前端遺漏的花括號與結束標籤，並完善 `sprout` 等動畫效果。
2. **探索菜單優化**：修復了人氣火焰（Flame）的顯示邏輯，並確保商品規格彈窗（Item Modal）能順利觸發。
3. **物資背包接續**：修復 `renderCartTab` 的渲染中斷問題，補全物資背包的刪除、總計與洋蔥號派遣提交邏輯。
4. **指揮中心與管理功能**：完整保留並修復代點模式、指揮官後台（人員收款/店家品項統計）、一鍵收退款、打烊封存等管理者核心邏輯。
5. **使用者體驗改善**：保留了選填稱呼功能，以及完整維持選單雙指滾動縮放（Panzoom）的流暢操作。
